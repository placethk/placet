# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

## Report a vulnerability

Do **not** open a public issue for a security problem.

Use GitHub's private reporting: **Security → Report a vulnerability** on [placethk/placet](https://github.com/placethk/placet/security/advisories/new).

Include:

- Affected Skill, script, or hook
- What an attacker could do
- Reproduction without secrets (redact tokens and private keys)

We will acknowledge the report and follow up with a fix or a documented limitation.
