# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful in issues, pull requests, and reviews. Harassment and personal attacks are not acceptable.

To report a conduct issue, use the same private channel as [SECURITY.md](SECURITY.md) (GitHub Security advisory), and mark it as a conduct report in the first line.
