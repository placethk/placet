# time-model

## Trigger

Natural language: `current time` / `model info` / `what time is it` / `which model`

Command: `/placet-now`

## Execution

1. Show the current time as `YYYY-MM-DD hh:mm:ss`
2. Query and report the model currently in use

## Outputs

| Output | Notes |
|------|------|
| Current time | Date and time in `YYYY-MM-DD hh:mm:ss` |
| Current model | Name of the AI model in this session |
